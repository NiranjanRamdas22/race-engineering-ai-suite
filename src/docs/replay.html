AI Replay Engineer

Replay real timestamps and measure what differs from a reference.

Engineering approach

  • Single-lap recordings provide timestamp, distance, speed, normalized pedals and gear. Browser interpolation matches the server reference.
  • Cumulative time delta uses elapsed time at matching distance. Braking uses the interpolated pedal threshold crossing, with measured early/late metres.
  • Session identifiers and increasing sequence numbers reject stale frames. Reset cancels the active AI request and clears gauges, plots, radio and voice.
  • One asynchronous coaching request runs per session. Browser voice is opt-in, prioritized, bounded, cancellable and adjustable.

Try the demo

Start the matched-reference demo at 4×: delta remains near zero. Reset, choose Late braking and resume to see measured coaching. Import silverstone-2024-ver.json as reference, then silverstone-2024-ham.json as recorded run for a sourced example.

Evidence and limits

The default speed profile is generated, not an official pole lap. Official sample files are labelled separately. Braking thresholds and sample rate limit measurement precision. X/Y guidance is unavailable without position channels in both recordings. Live UDP is deferred; the offline parser only accepts the tested F1 23 v1 telemetry packet.
