Validation & Methodology — 12 October 2026

Results below describe this local build and supplied data.

Measured checks

  • Telemetry: official cached 2024 Silverstone qualifying loaded and analysed; 18 circuit-metadata corners. Regression fixtures recover zero delta for identical laps and a known one-second offset.
  • 45 Python regression checks plus JavaScript reset, stale-response and recording-size checks passed after fixes. The independent review identified two chatbot defects, both fixed, but ended early at its usage limit; a complete independent sign-off is not claimed. The final test log is retained in .implementation/regression.log.
  • Seeded 10,000-frame simulator run: 88.1–112.3°C, 85–100% tyre remaining, bounded history and cooldown entries.
  • Instrumented stability run: 1801.0 seconds, 16,831 replay frames, 0 failures. Complete. Earlier stability run completed 1801.2 seconds with 0 errors.
  • All six web surfaces measured at 390, 768 and 1440 pixels without page-wide horizontal overflow. Desktop primary controls remain visible at its 390-pixel minimum client width; remaining content scrolls vertically.
  • Browser workflows include analysis, full-grid scoring, strategy changes, recorded replay/reset, unsupported questions, qualifying comparisons, keyboard dialogs and an incomplete import containing HTML displayed as text.

The 30-minute stability run preceded the final chatbot, braking-association and input-validation fixes. Those fixes passed targeted regression and browser checks; the unchanged simulator and queue lifecycle were covered by the soak. No second full independent review was completed.

Limits

Live game UDP and public deployment are deferred. Optional live LLM generation and audible output across every browser/device remain environment-dependent. This is a local portfolio demonstration, not a production race-control system or calibrated vehicle model.
