Race Summariser

Produce a debrief that keeps supplied evidence separate from generated explanation.

Engineering approach

  • Uses one event taxonomy across timeline filters and reports, including pit-cycle gains and retirement inheritance.
  • Validated JSON imports persist in SQLite. Omitted winners, dates, lap counts and events remain unknown.
  • Shipped race examples use refreshed FastF1 timing and concise sourced FIA report annotations. Selected timelines are explicitly incomplete.
  • Renders text safely and exports Markdown. Optional local AI identifies its actual engine and fallback reason.

Try the demo

Select 2024 Italian Grand Prix, choose the PIT CYCLE GAIN timeline filter, then Generate debrief. The strategy section includes Norris’s undercut. Export Markdown. Import the minimal example in the setup guide to check unknown-field handling.

Evidence and limits

A timeline is a selected set of supplied annotations, not a complete event detector. Stints use timing-feed lap groups. Generated interpretation may need source checking; the facts-only template is the deterministic default.
