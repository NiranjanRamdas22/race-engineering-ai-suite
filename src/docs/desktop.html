AI Race Engineer

Keep a local coaching display responsive during telemetry, coaching and speech.

Engineering approach

  • Retains Tkinter with main-thread widget updates and separate bounded telemetry, coaching and audio workers.
  • Includes start, pause, reset, scenario selection, recorded JSON playback at 1×/2×/4×, reference import and labelled tyre positions.
  • Bounds remaining tyre state to 0–100% and uses heating/cooling targets. Repeated event/corner warnings have a five-second cooldown with urgency escalation.
  • Opt-in Windows speech has volume, mute and an optional radio tone. Reset invalidates old coaching and clears queued voice.

Try the demo

Open the desktop demo, choose Balanced, press Use illustrative simulator, then Start. Pause and reset. For recorded comparison, load the VER JSON as reference and HAM JSON as run from data/recordings, then Start.

Evidence and limits

The simulator is illustrative, with no validated vehicle physics or game connection. Recorded tyre channels are optional and unknown channels stay unavailable. Guidance requires overlapping reference distance; lateral guidance additionally requires X/Y in the same coordinate system. Voice depends on installed Windows voices. The default coaching engine is deterministic rules.
